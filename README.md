# Besparingscheck webapp

Deze repository bevat een volledig front-end prototype van een "besparingscheck" in het Nederlands.

## Inhoud

- Meer-staps formulier (4 stappen)
- Validatie per stap
- Dynamische voortgangsbalk
- Indicatieve besparingsberekening op basis van ingevoerde kosten
- Resultaatscherm met uitsplitsing per besparingsgebied

## Lokaal draaien

Open `index.html` direct in de browser of start een simpele server:

```bash
python3 -m http.server 4173
```

Ga daarna naar `http://localhost:4173`.
